These agent skills sync across machines with [Skill Library](https://github.com/ianwijma/skill-library-skill).

- **Zero skills loaded by default:** nothing sits in the agent's context up front.
- **Query for what you need:** the agent asks the library for the skills a task needs and reads only those.
- **Synced:** every machine picks up new and updated skills from this repository.

Use them on another machine: `skill-library sync init {{url}}`
